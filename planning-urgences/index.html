Résumé du mois

⚙️ Générer un planning

L'application remplit automatiquement les postes (M, J, DJ, S, N) puis complète avec les repos (RH), les journées aménagées (JA) et les récupérations (REC) selon les règles du service. Les congés posés (CR) et les cases que vous avez verrouillées 🔒 ne sont jamais écrasés.

🧹 Effacer une période

Vide les cases d'une période (utile pour repartir de zéro). Les congés CR et les cases verrouillées peuvent être conservés.

🌴 Poser une absence

Posez un congé ou une absence sur plusieurs jours d'un coup. La case est verrouillée : la génération automatique ne l'écrasera pas. Cochez « réajuster » pour recalculer immédiatement les postes de la période concernée.

👥 Renfort / intérimaire

Nommez un remplaçant sur un emplacement libre, puis affectez-le à des postes ponctuels sans toucher au reste du planning. Les emplacements de remplacement se gèrent dans l'onglet Équipe.

📋 Absences et affectations verrouillées

👤 Effectif Quotité · roulement · groupe de week-end · compteur REC

Roulement : jour uniquement = ne fait jamais de nuit · équipe de nuit = fait partie du groupe habilité à la nuit ; les semaines où il n'est pas au roulement de nuit, il tient des postes de jour · nuit uniquement = référent de nuit, présent à chaque roulement et sur aucun poste de jour. Jour et nuit ne se mélangent jamais sur une même semaine.
Groupe WE : les groupes A et B travaillent un week-end sur deux, en alternance.
Ancre REC : date du dernier jour de récupération ; le suivant est posé automatiquement 6 semaines après.

🔁 Remplacer un agent (départ / nouvelle recrue)

Le nom est remplacé partout dans le planning, sans reconstruire l'historique : la ligne, ses congés et ses compteurs sont conservés. Choisissez une date d'effet si vous voulez repartir d'un compteur REC neuf pour la nouvelle personne.

💾 Sauvegarde des données

Les données sont enregistrées sur cet appareil uniquement (mémoire locale du navigateur). Exportez régulièrement un fichier de sauvegarde : c'est aussi le moyen de transférer le planning sur un autre poste ou de le partager avec une collègue.

🔑 Donner accès à une collègue

L'accès se donne par adresse e-mail, depuis le menu Partager de cette page (en haut à droite de la fenêtre). Deux niveaux existent :

Niveau à choisirCe que la personne peut faire
Peut consulterVoir le planning, changer de mois, imprimer, exporter. Aucune modification possible — les boutons ne s'affichent même pas.
Peut modifierTout ce qui précède, plus générer et modifier le planning. À réserver à qui vous remplace.

Cet onglet n'est visible que de vous. Personne d'autre ne le voit, même en cherchant : le registre ci-dessous est enregistré dans un espace réservé à la propriétaire de la page.

🔒 Deuxième barrière : le code personnel

Chaque personne inscrite reçoit un code nominatif, demandé à l'ouverture de la page. C'est ce qui protège votre travail si quelqu'un fait suivre le lien : le destinataire verra un écran de saisie, pas votre planning.

BarrièreCe qu'elle empêche

menu Partager		 Une personne à qui vous n'avez rien donné ne peut pas ouvrir la page du tout. Appliqué par le serveur : rien ne le contourne.
2. Le code personnel
ci-dessous		 Une personne autorisée qui transmettrait le lien ne transmet pas l'accès : il faut aussi le code, et vous savez lequel a servi.

Retirer quelqu'un du registre désactive son code immédiatement. Le bouton « Créer un code » en génère un nouveau et annule l'ancien — utile si un code a circulé. Tant qu'aucun code n'existe, la page s'ouvre sans en demander.
